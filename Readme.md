# Peddy - Pet Adoption Platform

Peddy is an all-in-one pet adoption platform where people can adopt various pets based on their category, gender, breed, age, and price.

## 5 Key features of the project

1. Users can easily browse pets based on 4 different category such as cats, dogs, rabbits, and birds.

2. Users can like pets that he/she likes

3. They can see the detail information such as breed, birth, gender, price, and vaccination status of every pet.

4. They can sort pets based on their prices (from highest to the lowest possible price)

5. Fully responsive mobile-friendly pet adoption platform

## ES6 features that used in this project

    - Arrow functions
    - ES6 array methods such as forEach, sort method
    - Enhanced Object Properties (Object Shorthand)
    - const and let for variable declaration
    - Handling promises with async/await for asynchronous operation
    - Template Literals
